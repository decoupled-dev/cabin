# Cabin library v0.1.0 — release readiness

Status: **library track ready for merge**; **do not git-tag `v0.1.0` yet**.

This page tracks the library release gate (tokens / Restriction Engine / Theme /
bars / Climate / Media). The marketing site track is separate
([PR #21](https://github.com/decoupled-dev/cabin/pull/21)).

## What ships (Alpha)

| Module | Coordinate / Soong | Contents | Stability |
| --- | --- | --- | --- |
| `cabin-tokens` | `dev.decoupled.cabin:cabin-tokens:0.1.0` / `CabinTokens` | Codegen from `tokens/cabin.tokens.json`; day/night schemes; night contrast locks (`warning` / `error` / `charging`) | Alpha |
| `cabin-compliance` | `…:cabin-compliance:0.1.0` / `CabinCompliance` | Restriction Engine + `Signal`; fail-closed unknown; bar + Climate/Media interaction gates | Alpha |
| `cabin-views` | `…:cabin-views:0.1.0` / `CabinViews` | Theme Kit; System/Status bars; `CabinClimateTileView`; `CabinMediaNowPlayingView` | Alpha |
| `cabin-compose` | `…:cabin-compose:0.1.0` / `CabinCompose` | Theme + bar + Climate/Media **parity** | **Experimental** |

Not a product / SystemUI dependency: `catalog/`, `apps/www`, `website/`.

No Material / AppCompat widget clones in library modules; colors come from
generated tokens (OEM demo hex only in tests / overlay samples).

## Consume

See root [README — Install / consume](../../README.md#install--consume-oems--app-developers).

```bash
./gradlew publishCabinToMavenLocal
# then: implementation("dev.decoupled.cabin:cabin-views:0.1.0")
```

Soong: `CabinTokens` + `CabinCompliance` + `CabinViews` only for SystemUI
([build-tree](../adoption/build-tree.md)).

## CI gates (must stay green)

```bash
python3 tools/check_soong_thin_deps.py
python3 tools/generate_cabin_tokens.py --check
python3 tools/test_generate_cabin_tokens.py
./gradlew :cabin-tokens:test :cabin-compliance:test :cabin-views:test :cabin-compose:test :catalog:test
```

Covers token drift, night safety locks, Restriction Engine fail-closed, and
Views/Compose chrome + Climate/Media unit tests.

## MVP frozen doc vs release track

[docs/mvp.md](../mvp.md) freezes tokens + RE + Theme + Views bars as the MVP
core and lists full domain **screens**/packs as non-goals. ClimateTile +

`main` — not full domain packs. Do not expand further without an explicit
scope change.
