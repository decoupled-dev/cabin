## What this site is (and is not)

This public site is a **thin docs shell**. It ingests the repo `docs/` tree.
Interactive component catalogs, live Compose demos, and versioned library
release notes are **not implemented yet** — see
[Components](/guide/components) and [Patterns](/guide/patterns).

Authoritative contracts live in the GitHub repository:
[decoupled-dev/cabin](https://github.com/decoupled-dev/cabin).
