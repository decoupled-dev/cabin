# Get started

Cabin's Alpha modules (`cabin-tokens`, `cabin-compliance`, `cabin-views`) are
in the repo. The Material 3 Compose kit, six look presets, and the opt-in
`cabin-screens` reference screens are **Experimental**. Maven coordinates are
**planned**, not published.

## Read first

1. [Vision](/docs/vision) — positioning and dual-stack story
2. [Product pillars](/docs/product/pillars) — glanceable, quiet, safe by default
3. [Tokens](/docs/design-language/tokens) — semantic + component contract
4. [Compliance](/docs/compliance/) — Restriction Engine overview
5. [MVP v0.1](/docs/mvp) — frozen scope before domain screens
6. [ADR 0006](/docs/adr/0006-material3-looks-and-tiers) — Material 3 base, looks, three tiers

## What this site is (and is not)

This public site is a **thin docs shell**. It ingests the repo `docs/` tree.
Interactive component catalogs, live Compose demos, and versioned library
release notes are **not implemented yet** — see
[Components](/guide/components) and [Patterns](/guide/patterns).

Authoritative contracts live in the GitHub repository:
[decoupled-dev/cabin](https://github.com/decoupled-dev/cabin).
