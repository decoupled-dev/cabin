Cabin now ships a **thin public docs shell** under `website/` (Docusaurus).

This is an early start relative to the original Phase 7 website milestone:
content is ingested from the repository `docs/` tree. Interactive component
catalogs, live demos, and library version switchers remain **later**.

See the [site plan](/docs/website/site-plan) and [roadmap](/docs/roadmap).
