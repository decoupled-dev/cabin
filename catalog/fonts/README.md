# Showcase fonts

The catalog's showcase bundles these fonts so each look renders as designed.
**Cabin libraries ship no fonts.** This folder is sample-app only and never
part of the `cabin-*` publish graph or an `Android.bp`.

All fonts are licensed under the SIL Open Font License 1.1. The license for
each family is next to this file. Source: <https://github.com/google/fonts>.
